

## notepad3和notepad4区别
- 开发主线：Notepad3 由 Rizonesoft 维护，是 Notepad2-mod 的延续；Notepad4 由 zufuliu 维护，是 Notepad2 的现代 C++ 重写版，性能优化是重点。
- 性能取向：Notepad3 稳定流畅；Notepad4 以速度和低内存占用为优先，有用户反馈“速度简直是飞起”，且内存占用更少。
- 现代工具链：Notepad3 功能全面；Notepad4 额外集成了 Web 开发工具（如 CSS/JS/JSON 压缩、URL 编解码）和表达式计算等实用功能。
- 语言更新频率：Notepad3 语言支持稳定；Notepad4 对新兴语言（如 Erlang、Elixir、Typst）和现有语言新版本的支持更新更频繁。
- 用户细节体验：Notepad4 的自动补全更强，但 Notepad3 在一些细节处理上被部分用户认为更好（例如对 Fortran 单行 if 语句的折叠判断更准确）。
